# 云团智能陪伴挂件技术概览

> 用途：供非技术人员了解项目，并作为 PPT 内容参考  
> 版本：小程序开发版 / 固件 `0.8.0` / 硬件 `A1`  
> 更新日期：2026-07-21

## 1. 项目是什么

“云团”是一套面向随迁老人的智能陪伴系统，由智能挂件、微信小程序、微信云端和 AI 语音服务组成。

它主要解决三件事：

- 用简单的微信小程序管理挂件和提醒；
- 通过手机或挂件与 AI 进行文字、语音交流；
- 让附近的云团挂件匿名发现彼此，在双方同意后建立伙伴关系。

整体技术链路：

**智能挂件（ESP32） → 蓝牙 BLE → 微信小程序 → 微信云函数 / 云数据库 → AI、语音识别和语音合成服务**

名词说明：BLE 是低功耗蓝牙；ASR 是把语音转成文字；TTS 是把文字合成为语音。

## 2. 每个功能使用的技术

| 功能 | 主要技术 | 技术起到的作用 |
| --- | --- | --- |
| 适老化双页面 | 微信小程序原生框架、WXML、WXSS、JavaScript | 构建设备页和伙伴页，放大文字与按钮，并实现左右滑动 |
| 挂件搜索与连接 | BLE GATT、微信 BLE API、ESP32 NimBLE | 让手机发现挂件、建立连接并自动重连 |
| 设备状态与电量 | ESP32 ADC、标准蓝牙电池服务 | 读取电池电压，将结果换算成百分比并显示在小程序中 |
| 提醒与查找挂件 | ESP32 GPIO、振动马达、LED、I2S 扬声器 | 接收小程序指令，通过振动、灯光和提示音提醒用户 |
| AI 文字聊天 | 微信云函数、兼容 OpenAI 的大模型接口、SSE 流式传输 | 在云端调用 AI，并把回答分段显示，减少等待感 |
| 手机语音聊天 | 微信 RecorderManager、腾讯云 ASR/TTS | 用手机麦克风录音，完成语音转文字和回答朗读 |
| 挂件 PTT 语音 | ESP32 I2S、IMA-ADPCM、BLE 音频传输、ASR/TTS | 通过挂件按键录音，把语音传到手机和云端，再把 AI 回答播回挂件 |
| 附近匿名相遇 | BLE 广播与扫描、RSSI 信号强度、临时匿名 Token | 判断两台挂件是否靠近，同时避免直接广播用户身份 |
| 招呼与伙伴关系 | 微信云函数、匿名凭证、云数据库事务 | 用户确认后建立双向伙伴关系，避免陌生人直接联系 |
| 伙伴文字聊天 | CloudBase 云数据库、本地缓存、增量同步 | 保存伙伴消息，先显示本地记录，再同步云端新消息 |
| 个人名片与联系方式 | CloudBase 云存储、云函数、双方确认流程 | 保存公开名片；联系方式只有双方同意后才会分享 |
| 缓存、隐私与数据删除 | 小程序本地存储、挂件 NVS、哈希、限流、定时清理 | 加快页面打开速度，保护身份和密钥，并支持删除个人数据 |

## 3. 三条关键技术链路

### 3.1 设备连接

挂件通过 BLE 与微信小程序连接，小程序读取电量和版本，并向挂件发送提醒、查找和设置指令。

### 3.2 AI 语音

用户说话后，系统依次完成录音、语音识别、AI 回答、语音合成和播放。挂件语音会边传输边处理，缩短等待时间。

### 3.3 匿名社交

附近挂件只交换临时匿名标识。用户查看公开名片并主动确认后，云端才会建立伙伴关系和聊天会话。

## 4. PPT 可直接使用的总结

- **软硬件结合**：ESP32 智能挂件通过低功耗蓝牙接入微信小程序；
- **AI 语音陪伴**：支持手机和挂件两种语音入口，并完成识别、回答和朗读；
- **隐私优先社交**：附近相遇保持匿名，建立关系和交换联系方式都需要双方同意；
- **云端业务保护**：身份验证、AI 密钥、社交关系、限流和数据删除都在云端处理。

当前仍属于原型阶段：固件 OTA、量产级通信加密、功耗与 EMC 等仍需后续完善。制作 PPT 时应将这些内容标为“后续优化”，不要写成已完成功能。
